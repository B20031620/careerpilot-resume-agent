# 高级AI Agent工程师 - 某头部AI公司

## 岗位描述

我们正在寻找一位高级AI Agent工程师，加入我们的核心Agent团队，负责设计和开发下一代AI Agent平台。你将有机会从零到一构建生产级AI Agent系统，直接影响千万级用户的产品体验。

## 岗位职责

1. 设计并实现AI Agent工作流编排引擎，支持多轮推理、工具调用、记忆管理
2. 构建RAG检索增强系统，优化知识检索的准确率和召回率
3. 设计Prompt工程框架，实现Prompt版本管理、A/B测试与自动优化
4. 优化LLM推理链路，降低延迟与成本，提升系统吞吐量
5. 参与Agent评测体系搭建，建立质量基线与监控告警
6. 与产品、算法团队协作，将研究成果转化为可落地的工程方案
7. 编写技术文档，参与技术方案评审，推动技术选型决策

## 任职要求

### 必备条件

- 3年以上Python后端开发经验，代码质量高，有生产环境部署经验
- 熟悉LangChain/LangGraph或类似Agent框架，有实际项目经验
- 熟悉大语言模型（GPT-4、Claude、DeepSeek等）的调用与优化
- 熟悉RAG架构，了解向量数据库（Milvus/Pinecone/Weaviate）原理
- 熟悉FastAPI或类似Web框架，能设计高性能RESTful API
- 熟悉Docker与Kubernetes，有容器化部署经验
- 具备系统设计能力，能独立完成模块级架构设计
- 良好的跨团队协作与沟通能力

### 加分项

- 有微服务架构设计与实施经验
- 有LLM评测或对齐（alignment）相关经验
- 熟悉消息队列（Kafka/RabbitMQ）和流式处理
- 有开源项目贡献（LangChain、LangGraph等）
- 了解Prompt Injection防御与AI安全
- 有团队管理或技术Mentor经验
